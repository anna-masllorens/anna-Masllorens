## Hi there 👋

This is Anna, a Telecomunications engineering master student. Currently working on some projects📡. 

I have been working on different projects, here's a little brief of them:
- **PAE-HP**: collaborative project between UPC and HP. Design and implementation for a communications bus in order to improve the HP SitePrint robot. Code developed mostly in C/C++. This code is implemented using Expressif libraries, as well as a CANopen node repo. 
- **SMOS-TB-processor**: implementation of multiple modifications into a code developed at Barcelona Expert Center (BEC), inside the ICM-CSIC. This repo processed data from the SMOS satellite in order to achieve a L3 product of Brightness Temperature measures from the SMOS satellite, by ESA. Mostly in C/C++ and some bash files. (Private repo)
- **Satellite-data processing**: scripts implemented in order to process satellite data and to plot maps. Mostly in Python.
